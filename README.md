# Topological Features in Time Series for Robust Classification

The goal of this project is to investigate whether persistent-homology features extracted from sliding-window embeddings in time series can help classify them, and whether they remain useful under noise or shifts in distributions.

## Planned Pipeline

Time series -> Sliding-window embedding  -> Point cloud -> Vietoris-Rips persistent homology -> topological features detection -> Classifier
